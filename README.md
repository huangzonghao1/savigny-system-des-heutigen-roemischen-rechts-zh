## 本版内容

EPUB 收录八卷正文及卷、小节导航，并在书末附页码对应、翻译疑难与未决记录、编校记录和德文词条字母排序的术语表。随附资料提供术语表 CSV、小节—原书页码对照、源页至 EPUB 映射、疑难和未决记录、来源说明及结构验收报告。 为公开发布，EPUB 末尾疑难记录中的本机来源路径字段已省略；未修改正文译文。
